# Compila Ordini

Pagina web che compila un file Excel a partire da un PDF d'ordine.
Tutto avviene nel browser: i file caricati non vengono inviati a nessun server.

- **Hopper**: Excel *catalog export*, quantità nelle colonne SOLID per taglia.
- **Verita**: Excel *order form*, WOMAN/MAN a pacchi (PACK ORDER) o a taglie singole (UNIT ORDER).

Librerie incluse: [pdf.js](https://github.com/mozilla/pdf.js) (Apache-2.0), [JSZip](https://github.com/Stuk/jszip) (MIT).
